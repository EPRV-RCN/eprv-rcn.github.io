Workshop Overview & Zoom Link

This workshop will cover best practices for how to develop compelling and competitive EPRV observing proposals, and feature representatives from NOIRLab, ESO, NEID, ESPRESSO, MAROON-X, and more. See below for the full schedule, including a list of speakers and topics.

The workshop will be hosted on Zoom at https://caltech.zoom.us/j/81135789227. We also plan to record the event and post the video to the RCN's YouTube channel (https://www.youtube.com/@EPRVRCN) for those who cannot attend in real time.

Request for Community Contributions

We will also be developing a new page on the RCN website to collect useful proposal development resources!
We are hoping the RCN community will contribute to this effort in a few ways:

  • If you have notebooks / scripts on how to generate synthetic RV data using your favorite code packages, we'd love to collect examples across multiple packages in addition to the real-time example that will be included in the workshop. (Bonus points if you're keen to record a walkthrough of the code that we can post on the RCN's YouTube channel as a tutorial, though this is not required!)
  • If you have previously accepted observing proposals that you're willing to share with the community, we'd like to provide examples of what a winning proposal looks like across multiple TACs
  • If you have notes on how to find/use the exposure time calculators for a given EPRV instrument, we'd like to set up instrument-specific resource sections (these could also include notes on how to access archival data, etc)

If you're willing to contribute to any of these areas, then please reach out to the RCN Leads via email (eprv-rcn.leads [at] jpl.nasa.gov) or via the RCN's Slack workspace and we will coordinate adding your resources to the website so that you don't have to spend time on that stage of things.
